# Typography

You can use typography CSS variables for family, size, weight, line-height and letter-spacing,
for example:

```css
.title {
  font-size: var(--hot-font-size-2x-large);
  letter-spacing: var(--hot-letter-spacing-dense);
  font-weight: var(--hot-font-weight-light);
  line-height: var(--hot-line-height-normal);
}
```

## Font family

**There are none to load.** Since 2026-08-27 the design system uses the
platform's own sans stack - no Archivo, no Barlow, no webfonts at all.

See [MADR 0014](https://docs.hotosm.org/decisions/0014-system-fonts)
for the rationale.

The three samples below therefore render identically - that is the point.

  style={{
    fontFamily: "var(--hot-font-sans)",
