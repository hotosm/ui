# Typography

You can use typography CSS variables for family, size, weight, line-height and letter-spacing,
for example:

```css
.title {
  font-size: var(--hot-font-size-2x-large);
  letter-spacing: var(--hot-letter-spacing-dense);
  font-weight: var(--hot-font-weight-light);
  line-height: var(--hot-line-height-normal);
}
```

## Font family

Archivo, Barlow and Barlow Condensed are self-hosted and bundled in
`style.css` / `style-core.css` - there is nothing to load separately.
Scripts they don't cover fall back to Helvetica (Apple) or Noto
(Android / ChromeOS).

See [MADR 0014](https://docs.hotosm.org/decisions/0014-ui-fonts)
for the rationale.

## Script fallbacks

Each line sets its own `lang`, as mixed-language content should. Latin text
stays in Archivo; other scripts use the fallback fonts. Check a script here
before adding `:lang()` tweaks for a new language.
