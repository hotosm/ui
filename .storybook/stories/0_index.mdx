# HOT Shared UI

<hot-logo></hot-logo>

Shared [Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)
built with [Lit](https://lit.dev) and themed for HOTOSM tools using
[WebAwesome](https://webawesome.com).

## Install

```bash
pnpm install @hotosm/ui @awesome.me/webawesome@3.11.0
```

`@awesome.me/webawesome` is a peer dependency. Pin it to `3.11.0`.

## Use It

Bundler usage - register everything up front so no custom element renders
undefined (see [Loading Strategies](?path=/docs/loading-strategies--docs)):

```js
import "@hotosm/ui/dist/style.css"; // WebAwesome base styles + HOT theme
import "@hotosm/ui/dist/webawesome-all.js"; // registers every wa-* element
import "@hotosm/ui/dist/components/header/header.js"; // hot-* components you use
```

```html
<hot-header title="My App"></hot-header>
```

Fonts are not bundled - add the Google Fonts `<link>` to your HTML (see
README "Fonts").

CDN / plain HTML / HTMX usage - raw dist files plus an import map for the
bare `@awesome.me/webawesome/...` imports in `webawesome-all.js` (see
[Loading Strategies](?path=/docs/loading-strategies--docs)):

```html
<html class="wa-theme-default wa-palette-hotosm wa-cloak">
  <head>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@hotosm/ui@1.0.0/dist/style.css" />
    <script type="importmap">
      {
        "imports": {
          "@awesome.me/webawesome/dist/components/": "https://cdn.jsdelivr.net/npm/@awesome.me/webawesome@3.11.0/dist-cdn/components/"
        }
      }
    </script>
    <script
      type="module"
      src="https://cdn.jsdelivr.net/npm/@hotosm/ui@1.0.0/dist/webawesome-all.js"
    ></script>
    <script
      type="module"
      src="https://cdn.jsdelivr.net/npm/@hotosm/ui@1.0.0/dist/hotosm-ui.js"
    ></script>
  </head>
  <body>
    <hot-header title="My App" show-login></hot-header>
  </body>
</html>
```

Boolean props are presence-based in HTML:

- Omit attribute => `false`
- Include attribute => `true`
- Use kebab-case attributes like `show-login`, `drawer`, `tabs-center-align`

See [Loading Strategies](?path=/docs/loading-strategies--docs) for guidance on
FOUC, first paint, and CDN loading tradeoffs.

See full integration details in `README.md` and component-specific docs.
